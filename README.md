# MP4 Downloader

A simple Python project for downloading YouTube videos in MP4 format using Jupyter Notebook.

## 🚀 Features

- Download YouTube videos
- Save videos in MP4 format
- Easy-to-use Jupyter Notebook interface
- Simple and beginner-friendly workflow

## 🛠️ Requirements

- Python
- Jupyter Notebook
- `yt-dlp` library

Install the required library using the following command:

```bash
pip install yt-dlp
```

## 📥 Installation and Usage

1. Clone this repository or download it as a ZIP file.
2. Install the required dependency:

   ```bash
   pip install yt-dlp
   ```

3. Open the `.ipynb` Jupyter Notebook file.
4. Run the code cell.
5. Enter the URL of the YouTube video when prompted.
6. Wait for the download to finish.

The downloaded video will be saved to the location specified in the notebook code.

## 📌 Supported Platform

- **YouTube:** Only YouTube video URLs are supported.
- Other video platforms are not supported by this project.

## ⚠️ Disclaimer

Use this tool only for videos you have permission to download. Users are responsible for complying with YouTube's Terms of Service and applicable copyright laws.
